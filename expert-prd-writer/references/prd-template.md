**Title**: [Product Name]
**Status**: [Draft / In Review / Approved]

**Date**: [YYYY-MM-DD]

## 1. Problem & Context
*   **The Problem**: What is the specific pain point? Who feels it?
*   **Why Now?**: Why is this the right time to solve it? (Market shift, tech maturity, etc.)
*   **Current Solutions**: How do users solve this today? Why is that insufficient?

## 2. Solution Overview
*   **Value Proposition**: What is our unique approach?
*   **Key Differentiators**: Why will users choose us over competitors?
*   **Scope (MVP)**: What is the minimum set of features to prove value?
*   **Out of Scope**: What are we explicitly NOT building right now?

## 3. Success Metrics
*   **North Star Metric**: The single key metric that best captures value delivered to the user.
*   **Guardrail Metrics**: Metrics to protect (e.g., latency, crash rate, cannibalization).
*   **Success Criteria**: Specific targets for launch (e.g., "Sync success rate > 99.9%").

## 4. User Stories
*   **Persona A**: As a [Role], I want to [Action], so that [Benefit].
*   **Persona B**: As a [Role], I want to [Action], so that [Benefit].
*   **Edge Cases**: Handling offline, errors, conflicts, etc.

## 5. User Experience (UX)
*   **Onboarding**: How does a new user get started? (First 5 minutes)
*   **Key Flows**: Description of critical user journeys.
*   **Design Principles**: (e.g., "Minimalist", "Native feel", "Accessibility first").

## 6. Technical Requirements (High Level)
*   **Platforms**: iOS, Android, Web, etc.
*   **Performance**: Latency targets, offline capabilities.
*   **Security/Privacy**: Encryption standards, data handling policies.
*   **Constraints**: Dependencies, legacy systems.
