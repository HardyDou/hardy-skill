# skill-test 使用指南

## 什么是 skill-test？

skill-test 是一个 **Claude Code Agent**，用于自动化测试和评估 Claude Code skills 的质量。

**核心价值**：
- 自动发现相关 skills
- 生成测试用例并执行
- 输出标准化评测报告
- 横向对比多个 skills

---

## 如何使用

### 前提条件

1. 在 `creator/` 目录下打开 Claude Code
2. `CLAUDE.md` 会自动加载（定义了 skill-test 的行为）

### 基本用法

#### 1. 搜索并测试相关 skills

```
测试 写文章 相关skill
```

**流程**：
1. 搜索本地 + skills.sh 上的相关 skills
2. 列出候选表格
3. 你选择要测试的编号（如：1 3 5）
4. 自动逐个测试并生成报告

#### 2. 直接测试指定 skill

```
测试 humanizer-zh
```

跳过搜索步骤，直接测试。

#### 3. 查看测试进度

```
进度
```

显示所有已完成的测试。

#### 4. 查看单个 skill 报告

```
报告 humanizer-zh
```

#### 5. 对比两个 skills

```
对比 humanizer-zh wechat-converter
```

## 产出物说明

### 目录结构

```
creator/
└── [业务类型]/          ← 如 writing
    ├── [skill名]/
    │   ├── input.md     ← 测试输入
    │   ├── output.*     ← skill 产出
    │   └── REPORT.md    ← 评测报告
    └── SUMMARY.md       ← 汇总对比
```

### REPORT.md 内容

- 测试时间和文件
- 四维度评分（1-5 分）
  - 输出质量
  - 响应速度
  - 指令遵循
  - 实用性
- 亮点
- 不足
- 结论

### SUMMARY.md 内容

- 总览对比表格
- 核心发现
- 推荐使用场景
- 横向对比
- 改进建议

## 注意事项

### 1. 不可直接调用的 skills

有些 skills 设置了 `user-invocable: false`，无法自动调用。

**表现**：skill-test 会手动按文档转换，但自动化程度低

**示例**：xiaohongshu-converter、wechat-converter

### 2. 评分标准

评分基于 Claude 的判断，可能存在主观性。建议：
- 结合实际使用体验
- 关注"亮点"和"不足"部分
- 查看产出物质量

### 3. 测试场景

每个 skill 只测试一个典型场景，可能无法覆盖所有功能。

## 常见问题

### Q1：如何添加新的业务类型？

直接说：
```
测试 [新业务类型] 相关skill
```

skill-test 会自动创建对应目录。

### Q2：可以重新测试吗？

可以。重新运行测试会覆盖之前的产出物。

### Q3：如何自定义测试场景？

目前 input.md 由 Claude 自动生成。如需自定义：
1. 手动编辑 `[业务类型]/[skill名]/input.md`
2. 重新运行测试

### Q4：评分标准可以调整吗？

可以。修改 `CLAUDE.md` 中的 REPORT.md 模板。

---

## 最佳实践

1. **先搜索再测试**：用"测试 xxx 相关skill"发现更多选项
2. **批量测试**：一次选择多个 skill，方便对比
3. **查看 SUMMARY**：汇总报告比单个报告更有价值
4. **保存产出物**：测试结果可作为 skill 选型的参考文档
